# 一体化安装包：不可降低的交付标准

用户确认（2026-08-30）：最终提供一个 Windows 安装包，集成完整创作功能及通过审核的开源组件。客户安装后，在统一设置页输入 API 即可使用。

## 必须内置

- 桌面运行时、界面、本机任务服务、数据库和迁移工具；不要求安装 Node、Python、数据库、Docker。
- FFmpeg、FFprobe、字幕渲染依赖及适当授权的字体；不依赖开发电脑 PATH。
- 一键生成模块、画布模块、视频重制模块；所有已承诺功能逐项验收，不能用占位页冒充完成。
- 开源组件编译进安装包，不要求用户手动装插件；许可证、版权声明及需要提供的源码随发布流程处理。
- API 统一配置、系统加密存储、能力检测、缺失能力说明、清晰错误；任何真实 Key 均不能随包分发。
- 项目、媒体、任务 ID、作者确认记录落盘。更新、重启和默认卸载不丢项目。

## 交付边界

软件集成本地工具并不等于附赠云端模型能力。填写的 API 必须具有对应文字、视觉、图片、视频和转写能力，并且有额度、网络连通。不能保证任意字符串或任意不兼容 API 都可用。

重制原片的 AI 视觉分析和转写需要兼容接口；不能将“没有转写接口”伪装为已完成台词核验。AI 生成必须联网；本地浏览、剪辑、保存不需要模型或高端显卡。

## 发布前必须通过

1. 干净 Windows 10/11 x64 标准用户安装；无开发环境、无全局 FFmpeg、无 Python、无本地模型。
2. 安装、首次启动、全部 API 设置、重启保密、更新、卸载保留数据与恢复备份。
3. 画布、一键生成、重制三条完整真实 API 流程，以及下载、逐段审核、字幕、音频、合成。
4. 断网、断电恢复、过期 URL、API 超时、额度不足、失败单段重试；不能重复提交已完成的计费任务。
5. 网络出口与密钥审查、依赖漏洞扫描、安装包签名/校验、第三方授权材料核验。

未完成这些验收前，任何生成的安装包只能标明“集成测试版”，不能标为正式全功能版。
