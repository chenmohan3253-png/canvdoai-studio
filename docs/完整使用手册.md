# CanvDoAI Studio 完整使用手册

本文面向直接使用 Windows 安装包的创作者、工作室管理员和二次开发者。软件本体不赠送模型额度，也不内置任何生产 API Key；生成内容需要使用者配置自己有权使用的接口。

## 五分钟开始使用

1. 从本项目 GitHub Releases 下载与当前源码版本一致的 Windows 安装包并完成安装。
2. 打开 CanvDoAI Studio，进入左侧“API 接口设置”。
3. 先配置“剧本 / 文本生成”：填写 Base URL、API Key，读取模型后选择文本模型。
4. 配置“图片 / 分镜生成”。同一服务商兼容图片接口时，地址和 Key 可以留空以共用剧本配置；模型仍须以服务商实际目录为准。
5. 配置“视频生成”：填写视频 API Base URL 和 Key，点击“测试视频接口 / 读取模型”。
6. 点击页面顶部“保存全部配置”。返回目标模块后刷新模型目录。
7. 第一次使用建议新建一个短测试项目，以 1～2 个镜头、低分辨率完成真实接口验收，再开始长任务。

> “测试连接成功”只证明相应目录或基础请求可访问，不等于账户有足够额度，也不等于所有模型都支持图片编辑、声音、指定时长或参考素材。

## 系统要求与安装

- Windows 10/11 x64。
- 建议至少预留 10 GB 磁盘空间；长视频、候选版本和导出文件会按素材量继续占用空间。
- 安装版应随包提供可合法分发的 FFmpeg/FFprobe。源码仓库因许可证合规不直接携带二进制文件。
- 不要求本地大模型或独立显卡；AI 推理通过用户配置的 API 完成。FFmpeg 拆镜、转码、字幕和合成在本机执行。
- 未签名安装包可能触发 Windows SmartScreen。只应从项目官方 Release 或你信任的发行方下载，并核对 Release 提供的 SHA-256。

项目、素材、历史版本和断点保存在 Windows 用户应用数据目录，不保存在安装目录。软件的“API 接口设置 → 本机数据”会显示实际路径并提供备份入口。卸载程序默认不应删除该数据目录。

## API 配置说明

### 1. 剧本 / 文本生成

兼容 OpenAI 风格的：

```text
GET  {Base URL}/models
POST {Base URL}/chat/completions
Authorization: Bearer <API Key>
```

Base URL 一般填写到 `/v1`。模型 ID 必须使用接口目录真实返回的值，不要把网页产品名称当作模型 ID。

用于剧本分析、角色和场景提取、分镜规划、结构化 JSON，以及生成失败后的提示词风险优化。服务商若不支持 `response_format`、多模态消息或部分采样参数，可能需要适配层处理。

### 2. 图片 / 分镜生成

兼容：

```text
POST {Base URL}/images/generations
POST {Base URL}/images/edits     # 参考图编辑时需要
```

只支持 `images/generations` 的服务可以完成普通文生图，但不能保证参考图编辑。图片返回值需要包含可下载 URL 或 base64 数据。每张资产支持查看、下载、按修改意见单独重做；重新生成会新增候选，不应覆盖已采用版本。

### 3. 视频生成

当前客户端适配 Dispatch/Seedance 风格的异步任务。模型、清晰度、画幅、时长、参考素材数量和是否原生带声音，以当前 Key 返回的能力目录为准。配置页测试不会创建付费视频任务。

视频接口至少要完成：

- 读取模型/能力目录；
- 创建异步视频任务；
- 查询任务状态和进度；
- 返回可下载的视频结果；
- 明确返回鉴权、余额、审核、参数、超时和供应商异常。

若供应商路径或字段与当前适配器不同，需要新增 provider adapter，不能仅通过修改 Base URL 解决。

### 4. 视觉分析

视觉服务使用 OpenAI-compatible `/chat/completions` 图片输入。可以共用文本接口，也可配置独立视觉 Base URL、Key 和模型 ID。

点击“自动检测并推荐视觉模型”时，软件会读取目录并用内置测试图进行小额实测，不上传用户视频。完整说明见[视觉模型自动检测使用说明](视觉模型自动检测使用说明.md)。

### 5. 语音转写（可选）

用于台词与声音质检，常见协议是：

```text
POST {Base URL}/audio/transcriptions
```

没有配置转写服务时，技术质检和作者人工试听仍可使用，但不能自动核对“字幕文字是否实际说出”。

## 一键成片

1. 在“项目”中新建项目，或从项目列表打开已有项目。
2. 进入“AI 一键成片”，输入剧本，选择画幅、清晰度、视频模型和配音策略。
3. 极速模式会在必要的人机确认点之间自动推进；专业模式保留角色/场景、分镜脚本和分镜图审核。
4. 运行 01～05，依次完成预检、剧本解析、资产提取、分镜规划和分镜图。
5. 检查每个角色图、场景图和分镜图。可放大、下载或填写修改要求后单独重新生成。
6. 确认分镜后从 06 继续：视频片段、声音字幕、自动质检、时间线合成、导出交付。
7. 每个视频片段应先选择“采用此版本”。未全部采用时，后续配音、质检和合成会阻止执行。
8. 失败镜头只重做失败项；不要通过重新运行整个项目来覆盖已经确认的素材。

运行状态包括等待、排队、生成中、等待作者确认、成功、失败、暂停和恢复。关闭软件或断电后重新进入项目，应从最后检查点继续；已完成且指纹未变化的结果不会重复计费生成。更换模型、画幅、清晰度或关键提示词后，相关下游结果会失效，这是为了防止混用不同规格。

## 创作画布

1. 进入“创作画布”，选择内置工作流模板或创建空白画布。
2. 依次配置文本、图片、视频等节点。视频节点必须先读取模型目录并选择当前 Key 可用的模型。
3. 节点通过端口连线传递提示词、参考图片、首帧、尾帧或视频结果。
4. 选择目标节点，点击“运行此节点及必要上游”。系统只运行缺失或已经失效的必要上游，不应重复运行仍有效的节点。
5. “重新生成新版本”会保留旧候选；“运行此节点及必要上游”优先复用已完成结果。
6. 任务提交后节点状态会显示排队/生成中，而不是继续显示“未生成”。
7. 可将一键成片和视频重制的资产同步到素材库，再在画布节点中引用。
8. 用“导出含素材迁移包”迁移到另一台电脑；API Key 不会写入迁移包，需要在目标电脑重新配置。

模板结构和使用场景见[内置工作流模板](内置工作流模板-1.1.0.md)。

## 视频重制

1. 导入原片。原视频留在本机应用数据目录。
2. FFmpeg/FFprobe 在本机完成探测、转场检测、镜头切分和关键帧抽取。
3. 客户端按镜头保留时间码，每批发送少量压缩关键帧到视觉接口；普通分析不上传完整原片。
4. 视觉接口返回人物、场景、动作、构图和台词归属等结构化结果。
5. 对静态帧难以判断的连续动作，可按需提交短低清片段；临时分析文件完成后清理。
6. 作者核对分镜，再以镜头为单位生成新图片和视频，最后完成声音、字幕、质检和合成。

分析批次和镜头结果具有稳定指纹，异常退出后只继续未完成批次。详细机制见[长视频视觉分析与断点恢复说明](长视频视觉分析与断点恢复说明.md)。

## 自动质检与作者确认

自动质检不是单一模型打分，而是多项证据组合：

- FFprobe 检查视频/音频轨、时长、分辨率、编码和文件可读性；
- 任务元数据检查镜头规格、结果完整性和重复提交；
- 可选语音转写核对台词、字幕与声音；
- 作者实际预览并决定采用、重做或“确认可用”。

质检必须标出具体镜头、命中的规则、检测证据和处理方式。机器提示是辅助意见；对于不影响交付的软性问题，作者可确认放行。文件损坏、缺少视频轨或无法解码等硬错误不应被忽略。

## 字幕和声音

- 平台合成字幕默认位于画面底部安全区，使用较小字体。
- 若模型自身在画面内生成文字，平台字幕会形成“双字幕”。这属于源视频烧录文字，不能通过关闭外部字幕无损去除；应在生成提示词中禁止画内文字并重做该镜头，或使用裁切/修复模型处理。
- 对白、旁白和内心独白都应作为明确的“必说台词”进入镜头数据。
- 台词超过单镜时长时，可自动延长到模型上限；超过模型上限必须拆分镜头。
- 原生带声音的视频与平台另行合成配音不要同时启用，否则可能重叠。

## 数据、备份和隐私

- API Key 使用 Windows 安全存储加密，界面不会回显完整密钥。
- 项目、素材、候选版本和断点保存在本机；远程供应商仍会收到执行生成所必需的提示词和素材。
- 导出的项目迁移包和普通备份不包含 API Key。
- 不要在 GitHub Issue、截图、日志或迁移包说明中粘贴真实 Key。
- 更换电脑时先备份项目与素材，在新电脑导入后再单独填写 API 配置。

## 常见问题

### 点击测试没有反应

先保存配置，再测试。检查 Base URL 是否包含正确版本路径、Key 是否有模型目录权限、网络是否可访问服务商。开发者工具或日志中出现 401/403 通常是密钥或权限，402 是余额，404 是路径/模型，429 是限流，5xx 是服务商或上游异常。

### 能读取模型，但不能生成

目录可读不等于生成权限可用。检查模型能力、账户额度、参考图数量、提示词长度、画幅/时长限制和内容审核。使用一个镜头、低清晰度进行最小付费验收。

### 视频一直显示“未生成”

若已经提交，正确状态应变为排队或生成中。仍为未生成通常表示本地参数校验未通过、任务没有真正提交或供应商未返回任务 ID。查看节点下方的具体错误，不要连续点击造成重复任务。

### 分镜图或视频重新生成按钮不能点

常见原因是项目正在运行、API 未保存、模型目录未读取、没有选择模型，或该素材已进入下游锁定状态。先暂停当前任务，完成缺失配置；已用于下游的版本应新建候选而不是原位覆盖。

### 刷新或断电后结果不见了

先确认打开的是同一项目，不要新建同名项目。到“本机数据”打开数据目录，确认数据库和素材仍存在。不要手工删除应用数据目录。若安装目录被移动，项目数据原则上不受影响。

### 生成失败后应该怎么处理

界面应提供三类操作：

1. 使用文本 API 智能降低审核风险后，仅重试失败镜头；
2. 作者填写明确修改要求后生成新候选；
3. 更换有权限且支持当前规格的模型后重试。

已完成、已采用且输入指纹未改变的镜头不会重新生成。

## 开发者构建

```bash
npm ci
npm run typecheck
npm test
npm run build
npm start
```

打包前在 `vendor/ffmpeg/` 放置 `ffmpeg.exe`、`ffprobe.exe` 和对应许可证文件，并确认你的二进制分发方式符合 LGPL/GPL。随后根据 `package.json` 中的构建脚本制作安装包。发布时应执行[发布验收标准](发布验收标准.md)，提供版本号、变更记录、SHA-256 和签名状态。

## 能力边界

- 软件不能保证任意声称“OpenAI-compatible”的接口完整兼容；服务商可能修改字段、鉴权、模型和计费规则。
- 自动化测试覆盖客户端逻辑和本地媒体链路，但不能替代真实 API 的付费端到端验收。
- 生成质量、审核策略、速度和价格由所选服务商与模型决定。
- 开源仓库不包含官方托管服务、计费系统、企业授权后台、生产密钥，也不授予 CanvDoAI 名称和 Logo 的商标使用权。
