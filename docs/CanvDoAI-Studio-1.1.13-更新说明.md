# CanvDoAI Studio 1.1.13 更新说明

- “创作画布 → 项目”和“项目 → 创作画布”均可删除画布项目。删除前必须输入完整项目名称确认。
- 删除会将该项目的画布、任务记录和专属素材记录归档到本机“最近删除”；可在创作画布页面恢复。媒体文件和其他模块共享素材不会被物理删除。
- 正在运行或排队的画布项目不允许删除，避免中断生成任务。其他项目不受影响。
- MCP 增加 `archive_project` 与 `restore_project`；归档调用必须提供项目 ID、完整名称及明确确认参数。
- 项目删除改用桌面软件内置的确认弹窗，避免 Electron 不支持浏览器 `prompt()` 时误显示“画布项目无法读取”。
- MCP 握手版本号同步为 1.1.13，并提供完整调用说明及隔离服务 17 项工具验收脚本。

验证：TypeScript 类型检查、309 项自动化测试、桌面生产构建及 17 项 MCP 隔离调用通过。此更新不改变生成模型或 API 配置。
