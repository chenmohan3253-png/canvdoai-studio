# CanvDoAI Studio 1.1.18 更新说明

1.1.18 是 Windows 10/11 x64 **桌面集成测试版**。本版把连续镜头、首尾帧与多参考素材、远端视频自动收片和新的供应商适配接入同一套桌面运行时，并扩展本机 MCP。它不是“所有供应商、全部平台页面均已生产验收”的声明。

## 已实现的新增功能与修复

### 连续镜头、首尾帧和有序参考素材

- 创作画布可为视频节点分别设置首帧、尾帧和有序的图片/视频/音频参考素材。多参考模式与首尾帧模式不能混用；缺少首帧却只给尾帧、素材类型错误、跨项目素材、重复素材和超过模型上限会在上传或生成前被拒绝。
- 新增“续接下一镜头”流程：从当前项目已归档的视频完整解码并提取实际最后一帧，保存源视频 `assetId`、SHA-256、最后帧索引、总帧数和算法版本，再把该图片连接为下一镜头首帧。点击续接只建立工作流，不创建视频任务、不消耗生成额度。
- 一键成片和视频重制新增首帧、尾帧及有序多参考输入的源码与界面实现。提交前会重新读取当前模型能力、时长、画幅、分辨率和参考数量；能力变化时停止，不静默降级成文生视频。
- 重制入口的“使用上一镜尾帧”只接受本项目相邻镜头已成功归档的明确版本；已提交版本不能被素材编辑覆盖。

### 远端等待与自动收片

- 远端视频超过本地轮询窗口、查询暂时断网，或远端成功但成品暂时下载失败时，任务进入 `WAITING_PROVIDER`，保留原远端任务 ID，并按原 ID 自动续查和归档，不重新上传参考素材，也不创建第二个生成任务。
- 软件重开后可恢复带保存 ID 的等待任务，并兼容旧版“远端仍在运行；已保存ID”的记录。账户、节点输入或引用素材变化时停止，避免把旧结果挂到新请求。
- 画布最近任务和 MCP 新增“仅查询原任务并收片”入口。供应商明确返回失败时才标记远端失败；提交结果未知且没有远端 ID 时，不会猜测或新建任务。

### 视频供应商和素材协议

- 新增极九 Seedance 2.5 `/v1/videos` 协议适配，按当前令牌 `/v1/models` 实际返回筛选指定模型，并支持同任务轮询及受认证的 `/content` 下载。参考素材仍需要独立的素材上传服务；客户端不会把极九视频 Key 转发给该服务。
- 画布、一键成片和重制共用素材上传回执校验，可保留私有 `object_key`，不会为了凑公开 URL 而伪造 CDN 地址。
- 本机音频素材导入增加 WAV 支持；素材下载名和媒体角色/顺序校验得到补强。
- 视频提示词固定规则继续抑制非剧情字幕和水印，但不再一概禁止剧情中明确要求的可读道具文字。

### 本机 MCP 扩展到 30 项工具

- 新增 `append_canvas_continuation` 与 `extract_video_last_frame`，用于建立连续镜头工作流和提取项目视频实际尾帧；两者都不会创建生成任务。
- 新增 `resume_provider_task`，只按本机原 `taskId` 续查已保存远端 ID 并收片，不接受 `force` 或费用确认参数。
- 保留 1.1.17 增加的 `get_video_route_limits` 与 `prepare_canvas_video_request`，用于只读检查路由能力目录和桌面软件实际待提交的视频请求；预检不会上传素材或创建任务。
- 新增受限维护工具 `unlink_provider_form` / `get_provider_form_unlink` 和只读回执核对工具 `inspect_provider_submission` / `get_provider_submission_inspection`。这些工具依赖专用桥接服务协议，表单清理能力默认关闭；工具存在不代表服务端已部署、已启用或清理已成功。

MCP 仍主要覆盖创作画布、项目素材、预检、连续镜头、原任务收片和上述受限维护，不等于已经控制 AI 一键成片、视频重制、时间线、API 设置或全平台每个按钮。完整目录与安全边界见 [MCP 调用说明](CanvDoAI-MCP-调用说明.md)。

## 本次验证证据

- 2026-11-01：`npm run typecheck` 通过。
- 2026-11-01：全量自动测试 58 个测试文件、428 项测试全部通过。
- 2026-11-01：`npm run build`、`npm run test:mcp` 和 `npm run test:desktop` 通过。MCP 冒烟严格核验 30 项工具和关键参数约束，并检查桌面会话重连前后目录一致。
- 发布流程增加安装包内桌面程序的隔离启动检查，通过后才上传安装包与 SHA-256 文件。

上述自动化主要使用本地临时库、测试视频和模拟供应商。尚未完成的验收包括：全量真实供应商付费生成、各家真实首尾帧/多参考能力、干净 Windows 安装与覆盖升级、跨机器迁移、长期自动收片，以及企业代码签名。不能用模拟测试替代这些生产验收。

已知状态提示边界：供应商返回 `manual_review` 时可能同时携带失败说明，目前画布仍可能显示通用等待提示，需要按原任务 ID 核对回执，不应据此重复生成；一键成片前置阶段发生上游 HTTP 502 时，部分进度卡仍会保留上一次的检查文案，需查看具体错误。这两项提示问题未在本版声称修复。

## 安装与升级提醒

- 发布工作流生成未签名的 x64 NSIS 安装包和 SHA-256 校验文件。Windows SmartScreen 可能显示“未知发布者”；请只从本仓库 Release 下载并核对校验值。
- 更新前先保存编辑、确认没有正在生成或等待收片的任务，再退出旧版。不要删除当前用户的应用数据目录。
- 第一次接入真实 API 时先使用单镜头、小额任务验证模型目录、素材上传、任务查询、成品下载和账单，再决定是否批量运行。
- MCP 工具目录在 Codex 会话启动时缓存；升级并打开 1.1.18 后，需要新开 Codex 聊天或重启 MCP 连接，才能看到 30 项工具。
