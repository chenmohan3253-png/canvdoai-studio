# CanvDoAI Studio 1.1.11 更新说明

## 本版变化

- 创作画布增加“新建项目”入口。每个新项目取得独立 ID，先选项目再创建画布；画布列表按所选项目显示，避免不同短剧或客户的画布混在一起。
- 新项目的画布只能引用本项目素材；保存和运行前都会校验素材归属，且不能直接把已有画布改挂到其他项目。旧版画布和迁移包继续可访问。
- 本机 MCP 增加 `list_projects`、`create_project`、`create_canvas`；`list_canvases` 可传 `projectId` 仅查看指定项目。创建项目或画布不会调用生成 API。运行节点仍须由用户明确授权费用并传 `confirmCost=true`。
- 更新[完整使用手册](完整使用手册.md)与[Codex MCP 连接说明](Codex-MCP-连接.md)，写明项目创建和隔离用法。

## 安装与升级

适用于 Windows 10/11 x64。安装包内置 FFmpeg/FFprobe 与本机 MCP 运行时；无需另装 Node.js、Python 或本地大模型。生成内容仍需在“API 接口设置”填写有权使用的接口和密钥。

升级前先确认没有正在运行的生成任务，退出 CanvDoAI 和旧 MCP 连接，再覆盖安装。不要删除 `%APPDATA%\canvdoai-desktop`；项目、素材、断点和加密 API 配置保存在该目录。升级后建议重新打开 Codex，使新 MCP 工具出现在工具清单中。

## 验证范围与已知边界

- 已通过 TypeScript 静态检查、299 项自动化测试、MCP 项目创建与重连模拟测试、Windows 打包及已安装版本的启动和 MCP 读取测试。安装包归档校验通过，包含主程序 EXE、FFmpeg/FFprobe 和 MCP 运行时。
- 在一台由旧版覆盖升级的电脑上，首次静默安装漏拷主程序 EXE 和一个 DLL；再次运行同一安装包后文件完整、哈希一致并正常启动。尚未定位该单机升级异常的根因。如升级后无法启动，请先重新运行安装包；仍失败时联系维护者，不要删除项目数据目录。
- 项目隔离用于防止本机画布和素材误混，并非 Windows 多用户权限隔离。旧版项目保留原有素材关系，以避免迁移时丢失历史结果。
- 本版未对全部供应商模型和完整长片工作流逐一付费验收；供应商审核、额度与参数限制仍以服务端为准。未知状态下不要反复提交，以免重复计费。
- 安装包尚无企业代码签名，Windows 可能提示“未知发布者”。只从本仓库的 GitHub Release 下载，并核对同页 SHA-256 文件。
