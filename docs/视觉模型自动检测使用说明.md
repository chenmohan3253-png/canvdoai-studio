# 原片画面识别：模型自动检测

## 用户操作

1. 在“API 接口设置”保存视觉服务 Base URL 和 Key。两项留空时沿用剧本接口和密钥；独立视觉服务器可分别填写。
2. 点击“自动检测并推荐视觉模型”。软件读取该接口的模型目录，优先验证独立配置的模型和目录声明支持图片的模型。
3. 每轮最多测试 4 个候选，找到第一个通过者就停止。通过者会自动填入“视觉模型 ID”。点击页面上方“保存全部配置”后正式生效；不会修改剧本文本模型。
4. 也可点击“只读取模型目录”，从下拉框选择模型再点“验证当前选择的模型”。服务商不提供目录时，可手动填写其提供的模型 ID 并验证。
5. 检测过程中显示当前模型和完成数量，支持停止。软件不会自动穷举整个目录；只在用户点击检测时调用。

## 验证依据和边界

- 使用两张软件在内存中随机生成的 128×128 色块图，每张有四个象限。请求中不给正确答案，必须返回正确的颜色和位置才通过。
- 与重制分析使用相同的 `/chat/completions`、多图 `image_url`、JSON 输出、`temperature` 和 `max_completion_tokens` 协议。诊断输出上限为 1000 tokens，实际分析上限为 3000 tokens。
- 每个模型一次图片分析请求，最长等待约 30 秒；目录查询最长约 15 秒。停止后不再提交后续模型；服务商可能仍对已收到的请求计费。
- 目录/名称只用于候选排序，并不证明具备视觉能力。通过测试仅说明当前接口具备基础多图识别和结构化输出能力，不代表复杂人物、动作或整部视频分析质量已经验收。
- 不上传用户视频、不重新生成视频，也不调用图片生成服务。测试图只存在内存；检测状态在本次软件运行中保留，重启后需重新验证。已保存的模型选择会保留。
- 换接口或 Key 后清除旧接口的检测结论。密钥仍由 Electron safeStorage 加密保存，不进入检测结果、日志或安装包。

## 失败处理

| 结果 | 含义与处理 |
| --- | --- |
| 基础验证通过 | 两张图片识别结果匹配。保存模型后可试用原片画面识别。 |
| 图片输入被拒绝 | 服务商明确拒绝图片输入；换视觉模型或核对供应商协议。 |
| HTTP 502 / 503 / 504、超时 | 网关、上游或网络暂时异常。标记“暂未验证”，不判定为模型不支持；稍后重试或选择其他模型。 |
| HTTP 401 / 403 | Key、账户分组或模型权限问题。本轮检测停止，先检查授权。 |
| HTTP 402 / 429 | 计费、额度或限流问题。本轮停止，不无限重试。 |
| HTTP 400 / 422（参数错误） | 核对 JSON 输出、temperature、max_completion_tokens、多图输入兼容性；不直接认定模型没有视觉能力。 |
| HTTP 200 但答案不匹配 | 可能忽略图片、输出不符合 JSON 要求或识别失败。不能冒充可用；可重试或换模型。 |
| 目录读取失败 | 已有目录保留；可以手动填写服务商模型 ID 单独测试。 |

语音转写仍是独立能力；视觉测试成功并不代表转写接口已配置或可用。
