# CanvDoAI Studio 1.1.14 更新说明

## 创作画布参考图上传修复

- 参考图超过安全大小时，由本机 FFmpeg 转为高质量 JPEG 后上传；本地原图和画布素材不修改。
- `/v1/assets` 使用明确的 multipart 边界和请求长度，提升与限制请求体大小的素材服务兼容性。
- 对 `fetch failed` 等短暂网络断开，仅重试一次素材上传；不会因此重提视频生成任务。供应商返回 HTTP 400 等明确错误不会自动重试。
- 若参考素材上传仍失败，画布会标明“参考素材上传失败”，并记录该镜头的视频生成任务未提交，避免把上传错误误认为生成错误。

## 验证范围

- 本地模拟 2 MiB 上传限额，验证超大 PNG 被压缩并可完成 multipart 上传。
- 自动化测试验证上传失败时不会调用 `/v1/video-jobs`，也不会将节点标记为已提交。
- 未重新提交此前失败的远端镜头；供应商端真实上传与计费状态仍需通过一次用户确认的试运行核验。

## 跨任务使用

- 新增 [跨任务 MCP 使用说明](CanvDoAI-跨任务使用说明-1.1.14.md)，提供可复制到其他 Codex 任务的操作指令。
- 同一画布同时只允许一个运行任务；不同画布可并行，但会各自使用 API 额度。运行结果以 `get_task_status` 为准。
