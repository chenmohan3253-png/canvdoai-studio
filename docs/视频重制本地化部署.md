# CanvDoAI Studio 视频重制本地化部署

本文说明视频重制需要哪些本地组件、安装包用户是否要另外下载插件，以及从源码构建时如何放置和验证媒体工具。

需要 API 采购、工作室部署或技术支持，可扫码软件内官方微信，或发送邮件至 `chenmomo3253@gmail.com`。

## 先看结论

| 使用方式 | 是否需要另装插件 | 必需内容 |
| --- | --- | --- |
| 使用官方 Windows 安装包 | 不需要 | 安装包应内置 FFmpeg/FFprobe；用户只需配置有权限的 API |
| 从 GitHub 源码启动 | 需要准备媒体工具 | `vendor/ffmpeg/ffmpeg.exe`、`vendor/ffmpeg/ffprobe.exe` 和对应许可证材料 |
| 工作室分析服务器增强 | 可选 | PySceneDetect/OpenCV 可作为复杂转场增强器，但当前客户端不会因安装它而自动启用 |

软件不要求下载本地大模型，也不要求独立显卡。AI 剧本、图片、视觉和视频生成通过用户在“API 接口设置”中填写的接口完成；本地 FFmpeg/FFprobe 只负责媒体处理。

## 安装包用户

1. 安装与源码版本一致的 `CanvDoAI-Studio-*-Setup.exe`。
2. 启动软件，进入“API 接口设置”。
3. 配置剧本/文本接口、图片/分镜接口和视频接口；原片分析还要配置支持图片输入的视觉模型。
4. 点击每一项测试按钮读取模型，保存设置。
5. 进入“视频重制”，导入一段短视频进行首次验收。

安装包必须随包携带 FFmpeg/FFprobe。若界面提示“未找到 FFmpeg”或“FFprobe 不可用”，说明安装包不完整，不能通过让普通用户自行修改系统 `PATH` 作为正式解决方案，应重新安装完整发行包。

## 从源码构建

### 1. 准备 FFmpeg/FFprobe

从 [FFmpeg 官方下载页](https://ffmpeg.org/download.html)选择 Windows 构建。项目不指定第三方二进制发行商，也不保证任意构建都满足你的商业分发要求。下载后把文件放成：

```text
canvdoai-studio/
  vendor/
    ffmpeg/
      ffmpeg.exe
      ffprobe.exe
      LICENSE.txt          # 使用的二进制许可证
      SOURCE-NOTICE.txt    # 对应源码/构建来源与版本说明
```

不要只复制两个 EXE 后就宣称许可已经完成。正式分发前需要根据实际编译选项核对 LGPL/GPL、源码提供义务、版权声明及依赖许可。

### 2. 验证媒体工具

在 PowerShell 中运行：

```powershell
.\vendor\ffmpeg\ffmpeg.exe -version
.\vendor\ffmpeg\ffprobe.exe -version
```

两条命令都应输出版本和构建信息。随后安装依赖并执行：

```powershell
npm ci
npm run typecheck
npm test
npm run build
npm run test:desktop
```

`test:desktop` 应验证 Electron 隔离桥、本地媒体服务、内置 FFprobe 和视频重制界面可以启动。

### 3. 打包

```powershell
npm run package
```

项目通过 `extraResources` 把 `vendor/ffmpeg/` 复制到安装包资源目录。打包完成后必须在一台没有 Node.js、没有系统级 FFmpeg、没有开发环境的 Windows 10/11 x64 电脑上安装验证。

## 视频重制还需要哪些 API

### 视觉分析

视觉分析使用支持图片输入的 OpenAI-compatible `/chat/completions`。可以和文本接口共用，也可以配置独立的 Base URL、Key 和视觉模型 ID。软件会对关键帧分批分析；普通流程不上传整段原视频。

### 图片和视频生成

镜头重绘需要图片生成/编辑接口；动态重制需要软件当前支持的视频异步任务接口。能读取模型目录不代表账号一定拥有生成权限，首次使用应以短片和低分辨率进行小额真实验收。

### 语音转写

语音转写不是重制启动的硬依赖，但用于核对对白、字幕与声音。没有转写接口时仍可以人工试听和进行 FFprobe 技术检查。

## PySceneDetect 是否必须

不必须。当前客户端默认使用内置 FFmpeg 的转场检测、关键帧抽取和媒体探测。PySceneDetect 适合部署在工作室分析服务器上，作为快速剪辑、渐变转场或复杂镜头边界的增强器。

官方项目：[Breakthrough/PySceneDetect](https://github.com/Breakthrough/PySceneDetect)

注意：仅在服务器安装 PySceneDetect 不会让 CanvDoAI 自动调用它。需要额外实现服务端任务接口、任务状态、时间码 JSON 返回、临时文件清理和失败重试，再由客户端适配该接口。没有完成这些适配前，应继续使用默认 FFmpeg 流程。

## 数据流和存储

```text
原视频保存在客户端
  → FFmpeg 本地探测、拆镜和抽取关键帧
  → 压缩关键帧分批发送视觉 API
  → 结构化 JSON 返回客户端并保存断点
  → 作者确认分镜
  → 图片/视频 API 按镜头生成新版本
  → FFmpeg 本地完成声音、字幕和时间线合成
```

项目、素材、候选版本和断点保存在 Windows 用户应用数据目录。API Key 使用 Windows 安全存储加密，不应写入源码、安装包、迁移包或 GitHub Issue。

## 最小验收清单

1. FFmpeg 和 FFprobe 均能从安装包资源目录运行。
2. 导入视频后能读取时长、分辨率、视频轨和音轨。
3. 能识别镜头边界、抽取关键帧并保存起止时间码。
4. 视觉接口能返回结构化镜头分析。
5. 中断后重新进入，只继续未完成批次。
6. 失败镜头能单独重试，不覆盖作者已采用版本。
7. 合成结果由 FFprobe 验证含可读视频轨；需要声音时还应包含音频轨。
8. 在没有开发环境和系统级 FFmpeg 的干净电脑上完成安装验收。
