# 连续镜头与首尾帧

## 软件能力与视频渠道分离

CanvDoAI 保存首帧、尾帧、参考素材、来源版本和连线；视频渠道负责生成。
这些工作流数据不绑定 Higgsfield。更换已接入的渠道后，可以继续使用相同工作流，
但必须重新选择该渠道支持的模型、分辨率、时长和画幅。
“可接不同 API”不等于“任意 API 无需适配即可使用”。

| 输入方式 | 渠道必须支持 |
| --- | --- |
| 上一段实际尾帧作为下一段首帧 | `image_to_video` |
| 首帧加指定结束画面 | `first_last_frame` |
| 角色图、参考视频、参考音频 | `multi_reference`，并符合渠道的类型和数量限制 |

不支持的能力必须在上传和生成前拒绝，不能丢弃图片后改成文生视频。

## 画布操作

1. 选择视频生成节点，或已导入的视频素材节点。
2. 点击“续接下一镜头”。画布会增加“提取视频尾帧”和“下一镜头”两个节点。
3. 填写下一镜头的动作、运镜和台词；确认模型支持首帧。
4. 如需控制结束画面，在下一镜头的“尾帧”中选择图片。
5. 确认运行。软件按依赖顺序取得上一段成品、提取真实最后一帧，再提交下一镜头。

点击续接只建立流程，不生成、不收费。实际运行视频节点仍可能产生渠道费用。
下一镜头不会复制上一镜头的提示词、镜头 ID、随机种子或已生成版本。
首尾帧模式与多参考模式不混用。

## 提取与复用

- FFprobe 完整统计解码帧数，再由 FFmpeg 提取对应最后一帧，不按平均帧率估算时间点。
- 保存 PNG、源视频 assetId、SHA-256、零起始帧索引、总帧数和算法版本。
- 视频内容未变时复用已提取图片；换视频版本后重新提取，旧图片和候选仍保留。
- 更换 API 不会使本地尾帧失效。未知状态的远端生成任务仍沿用原账户保护，不向新账户重复提交。
- 黑色或模糊的实际尾帧不会擅自替换成更早的帧，需要作者审核。
- 当前提取针对本项目已归档的视频，使用软件自带 FFmpeg；不会向 Higgsfield 上传或调用生成接口。

## 共享入口

`POST /api/studio/asset/last-frame` 接收 `{ "projectId": "...", "assetId": "..." }`。
此为桌面软件受会话认证保护的内部接口，不是公网视频生成 API。
返回当前项目图片及 `derivation` 来源记录，供其他制作模块复用。

MCP 提供 `extract_video_last_frame` 与 `append_canvas_continuation`。
它们均不创建付费视频任务。生成仍须通过正常确认流程。

## 验收边界

自动测试覆盖真实视频逐像素尾帧比较、单帧、变帧率、版本更新、缓存、项目隔离、
不同模拟视频渠道的首尾帧映射，以及不支持能力时禁止提交。
模拟渠道测试不能替代真实服务商生成验收。

画布、一键成片与重制已具有通用素材入口的源码实现；全入口真实渠道验收尚未完成。
未完成全流程验收前，不将源码改动视为本机安装版已经更新。
画面相接不能保证动作、光线或声音自然衔接，成片仍需逐镜头检查。

### 2026-10-18 通用适配契约

- 一键成片支持只有 `first_last_frame` 能力、没有 `image_to_video` 能力的新模型，不按模型品牌筛选首尾帧功能。能力仍以当前 API 目录为准。
- 重制入口逐镜保存首帧、尾帧和有序图/视频/音频参考；保存草稿不创建生成任务。已提交版本不可被素材编辑覆盖。
- 重制的“使用上一镜尾帧”只接受本项目相邻镜头的明确已成功版本。读取本机归档、验证 SHA-256、完整解码提取最后一帧，再上传该 PNG 到当前所选 API 的素材服务。不会把源视频或 Higgsfield 会话交给新渠道，也不会自动生成下一镜。
- 提取记录包含来源任务、源视频 SHA-256、最后帧索引和总帧数。它与渠道模型 ID 分开保存；同一张 PNG 可交给其他已适配且具备相应能力的 API。
- 帧模式只发 `first_frame`、`last_frame`；参考模式只发 `reference`。顺序、内容校验值参与幂等键，预览地址和签名刷新不改变输入身份。前后帧不会被悄悄删除或改成普通参考图。
- 新 API 适配器必须分别映射能力目录、素材上传、首尾帧角色、时长/画幅/分辨率、任务创建、原任务查询和结果归档。只提供 OpenAI 风格文本接口或文生视频接口，不足以支持首尾帧。
- 不支持的能力、变化的模型参数、错误类型和不确定的远程任务均停止；不切换到另一模型、另一账户或文生视频重新提交。
- 自动测试已覆盖两种模拟第三方供应商的真实解码帧转发、仅首尾帧模型的界面选择，以及不同适配器下重制尾帧的归档读取与映射。模拟测试不是每家真实 API 都已验收的承诺。

“首尾画面一致”不是“动作、光线、镜头运动和声音必然无缝”。正式成片仍要逐镜检查，必要时生成桥接段或做声音连续处理。本机更新与同事安装包仍等待完整真实服务商验收。
