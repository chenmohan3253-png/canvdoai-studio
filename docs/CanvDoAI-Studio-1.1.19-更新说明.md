# CanvDoAI Studio 1.1.19 更新说明

本版修复视频提示词上限与实际服务能力不一致、请求被明确拒绝后仍显示“提交结果未知”的问题。安装包为 Windows x64 桌面集成测试版。

## 提示词与模型能力

- 在“API 接口设置 → 已向服务商确认的提示词上限”中，按当前接口地址和精确模型 ID 保存经服务商确认的限制，例如 `seedance-2.0:standard` 的 `15000` 字符。保存全部配置后生效。
- 画布界面、MCP 预检、实际生成共用有效上限；一键成片与视频重制移除原有固定长度的静默截断，最终内容超限时在本地明确报错。
- 上限包含上游文本、分隔符、平台附加规则和对白。按 JavaScript UTF-16 字符单位计数；多数中文汉字计 1，部分表情计 2。15000 是最终提交预算，不是额外附加文字之外的正文预算。
- MCP 同时返回 `catalogReportedPromptLimit` 与 `localPromptLimitOverride`，保留目录原值和本机确认值的区别。设置只作用于该接口与模型，不会提升其他模型，也不会修改供应商服务端能力。

## 拒绝状态与防重复提交

- HTTP 错误保留脱敏后的状态码、字段路径、`message`、`detail`、`errors` 和请求 ID，避免只显示 `invalid request` 而丢失具体原因。
- 创建任务时明确的参数或权限拒绝（400、401、403、404、405、413、415、422）记为 `REJECTED`。相同尝试再次运行会显示原拒绝信息，不自动发起另一笔请求。
- 断网、超时、未收到任务 ID、408/409/429 与 5xx 等不确定结果继续保留 `UNKNOWN` 保护。已有远端 ID 继续按原 ID 查询，不重新创建任务。
- 修正请求后，只有明确选择“重新生成”才建立新的尝试。升级不会批量清除历史未知任务；旧数据须结合精确幂等键与原始拒绝证据单独核对。

## Seedance 素材格式

- Dispatch 协议下 `seedance-*` 模型的素材，在已取得合法 `url`/`cdn_url` 时发送最小 `{url, role, order}` 引用格式，覆盖画布、一键成片与重制入口。
- 不伪造素材 URL；只有 `object_key` 的回执保留原形状。Wan、极九等其他协议保持各自适配。
- 这是客户端兼容修复，不能仅凭模型名称或客户端测试证明供应商内部模型来源，也不代表任意 422 都已被解决。

## 其他 Codex 聊天使用步骤

1. 打开更新后的 CanvDoAI Studio，保持软件运行。
2. MCP 调用 `list_projects`、`list_canvases`，固定目标 `projectId/canvasId/nodeId`。
3. 调用 `get_video_route_limits`，核对 `adapterVersion` 为 `1.1.19` 及该模型的实际上限。
4. 调用 `prepare_canvas_video_request`，核对完整最终提示词、模型、时长、分辨率、画幅和素材映射。该步骤不上传、不生成。
5. 有原远端 ID 的任务使用 `resume_provider_task`；不要把已有任务当作全新镜头重投。仅在明确拒绝或确认未提交且已获生成授权时，修正参数后发起一次新尝试。

原有项目、素材、生成结果及加密 API 配置应保留。企业代码签名尚未配置；请从本仓库 Release 下载并核对 SHA-256。安装后的真实生成能力还取决于所配置供应商、授权额度及模型服务状态。
