# CanvDoAI Studio 1.1.15 更新说明

## 本次更新

- 素材中心改为“总素材库 + 各项目独立素材库”。项目素材按 `projectId` 隔离，可按集数、场景、镜头、角色和素材 ID 查找。
- 素材增加审核状态、跨项目复用许可、授权依据及内容校验值。总库只接收已审核、已确认复用权的项目素材；跨项目使用时必须显式引用到目标项目，获得新的项目 `assetId`，不直接修改原件。
- 画布图片/视频生成节点可标注镜头归属。带集数、场景、镜头或角色标签的参考素材若与目标节点不符，保存时会拒绝，降低跨项目或跨镜头误用。
- MCP 增加 `list_shared_assets`、`update_asset_catalog`、`promote_asset_to_shared`、`reference_shared_asset` 四项工具，共 21 项。`get_canvas`、`list_assets` 和节点编辑同时支持查看或设置归档与镜头信息。详细顺序见 [MCP 调用说明](CanvDoAI-MCP-调用说明.md) 和 [分层素材库说明](素材库分层与MCP归档.md)。
- 素材中心界面更新为项目侧栏、素材卡片、审核标记及归档面板。
- 视频提示词额度改为按当前模型能力目录计算，并显示节点正文、上游文字、分隔符和自动附加内容各自占用；最终提交前仍会重新校验，避免显示值与实际提交内容不一致。

## 已验证范围与注意事项

- 本次源码通过 TypeScript 静态检查、322 项自动化测试、生产构建及 21 项工具目录的隔离 MCP 重连测试。安装版启动、FFprobe、本机加密、已安装 MCP 的 21 项工具目录及项目/总库只读调用均已验证。隔离测试不向真实视频供应商提交任务，不产生生成费用。
- 原有素材不会自动被标为“已审核”或迁入总库；需要制作人员实际核对身份、画面质量及授权后再标记。角色三视图/定妆板也不会因升级自动生成。
- MCP 当前控制创作画布与素材库；AI 一键成片、视频重制、最终剪辑等并非全部由这 21 项工具覆盖。跨项目引用不生成新内容，付费视频生成仍须另行授权。
- 安装包尚未进行企业代码签名。Windows 可能显示“未知发布者”；只从本仓库 Release 下载并核对同页 SHA-256。
