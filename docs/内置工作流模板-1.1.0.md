# CanvDoAI Studio 1.1.0 内置工作流模板

日期：2026-09-19

## 已接入

- 专业短剧：原始剧本 → 剧本拆解 → 分镜规划 → 分镜关键帧 → 分镜视频 → 成片交付。
- 极速短视频：主题与要求 → 短视频脚本 → 主视觉 → 有声短视频 → 成片输出。
- 小说推文 / 漫剧：小说章节 → 短剧改编 → 人物与场景视觉设定 → 漫剧分镜图 → 动态漫剧镜头 → 章节成片。
- 营销口播：产品卖点与限制 → 合规口播脚本 → 口播首图 → 口播视频 → 营销成片。
- 原片重制：重制要求 + 原片关键帧 → 关键帧重绘 → 重制视频镜头 → 重制成片。
- 空白画布：保留自由搭建入口。

## 使用规则

模板只创建本机节点、连线和默认提示词，不调用 API，也不产生费用。创建时如果视频模型目录已经成功读取，模板会预选目录中的第一个可用模型；没有读取到模型时保留为空，用户需要在视频节点中选择模型后再运行。

所有模板继续复用现有能力：统一 API 设置、本机加密密钥、SQLite 事务存档、断点恢复、输入未变化时复用、候选版本、采用版本、单节点重做、图片放大和媒体下载。

## 开源项目处理

- React Flow 继续作为画布基础库；模板编排、提示词和节点组合均由本项目独立实现。
- MoneyPrinterTurbo 只作为公开工作流阶段的产品参考，不复制源码、不捆绑 Python 应用。
- XState 暂不引入；现有 SQLite 断点任务已覆盖当前规模，等待团队协作和多分支审核复杂度达到迁移门槛。
- PySceneDetect 不进入默认客户端，避免要求客户额外安装 Python/OpenCV；可在未来的服务器分析版中作为可选增强。
- OpenTimelineIO 暂不打包，后续先做 OTIO JSON 导出和真实剪辑软件往返测试。
