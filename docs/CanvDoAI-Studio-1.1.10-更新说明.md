# CanvDoAI Studio 1.1.10 更新说明

## 本版变化

- Windows 安装包内置本机 MCP 运行时。Codex 可以读取画布及任务状态，并在用户明确授权 API 消耗后运行画布节点；Codex 配置中不需要填写业务 API Key。
- MCP 在桌面软件重启后重新取得本机会话；已验证同一个 MCP 进程能够读取重启前后的会话。
- Wan 3.0 使用专用异步创建与轮询路由：`/api/v1/services/aigc/video-generation/video-synthesis`、`X-DashScope-Async: enable`、`/api/v1/tasks/{task_id}`。Seedance 等通用模型继续使用原有 `/v1/video-jobs`。
- 参考图上传时正确识别 PNG、JPEG、WebP；视频节点的原生音频开关纳入缓存指纹；服务商拒绝时尽量显示可操作的错误原因，同时遮蔽已配置的 API Key。
- 修复 GitHub 标签构建时打包器隐式尝试发布、因没有打包阶段令牌而失败的问题。打包与发布现在由两个明确的步骤执行。

## 安装与连接

适用于 Windows 10/11 x64；内置 FFmpeg/FFprobe 与 MCP 所需的 Node.js 运行时，不要求客户安装本地大模型。安装后在“API 接口设置”填入自己有权使用的接口和密钥。Codex 的配置、工具权限及费用确认规则见 [Codex MCP 连接说明](Codex-MCP-连接.md)；其他功能见 [完整中文使用手册](完整使用手册.md)。

升级前请确认没有仍在运行的生成任务，退出桌面软件后覆盖安装。不要为升级而删除 `%APPDATA%\canvdoai-desktop`，其中保存项目、画布和加密配置。

## 验证范围与已知边界

- 静态检查、295 项单元测试、应用构建、MCP 重连模拟测试，以及本地打包后的启动与 MCP 读取均已通过。GitHub 云端发布结果需以本 Release 的安装包和 SHA-256 文件实际出现为准。
- Wan 3.0 链路已用单个 8 秒、480p、9:16、带首帧和原生音频的真实镜头验证受理、轮询及保存版本。整部短剧的全部镜头与最终合成尚未完成验收，不能仅凭首镜成功认定所有模型与素材均可用。
- 供应商的内容审核、额度和上传大小限制由其服务端决定。未知状态下不要重复提交，以免重复计费。
- 安装包目前没有企业代码签名，Windows 可能显示“未知发布者”。请仅从本仓库的 GitHub Release 下载，并核对同页 SHA-256 文件。
