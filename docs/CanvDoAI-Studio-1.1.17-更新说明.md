# CanvDoAI Studio 1.1.17 更新说明

本版为创作画布增加两项只读 MCP 预检工具，共 23 项：`get_video_route_limits` 读取当前路由的模型能力目录与客户端执行的提示词门禁；`prepare_canvas_video_request` 从指定画布视频节点导出软件将提交的准确提示词、参数和项目素材映射。两项工具均不上传素材、不启动视频生成，也不消耗生成额度。正式运行与预检共用同一套视频提示词构造与参数校验，避免预检结果和提交内容分叉。

预检会明确区分本地素材 ID 与供应商素材 ID：上传前 `providerAssetId` 为 `null`，不能把预检当成供应商接收凭据。能力目录上限也只标注为当前客户端路由的上限，不声称已核实供应商内部模型上限。Wan `prompt_extend` 后的内部提示词仍不可见；如需完整交付证据，应在正式提交后另行保存任务和供应商回执。

调整视频提示词固定后缀：继续抑制非剧情字幕与水印，但不再一概禁止剧情中明确要求的可读道具文字。原有画布内容不会被自动改写；运行前用新预检工具核对最终提示词。

验证范围：TypeScript 静态检查与相关 13 项测试通过。完整测试共 323 项，317 项通过，另 6 项因本次受限验证环境禁止本机环回连接或创建目录联接而未能验收；这 6 项不涉及新增预检功能，不能据此宣称全套测试通过。未对真实供应商发起付费视频任务。

本机已生成 Windows x64 便携版 ZIP，内含 FFmpeg/FFprobe 与 MCP 所需运行时；解压整个 `win-unpacked` 文件夹后运行其中的 `CanvDoAI Studio.exe`，不能只复制单个 EXE。本次受限构建环境禁止执行 NSIS，因此 **1.1.17 的 Setup.exe 安装向导尚未生成、未发布**。便携版未进行企业代码签名，Windows 可能提示“未知发布者”；请核对随包 SHA-256。试用前先确认没有运行中的生成任务，保存未完成编辑并退出旧版软件；正式覆盖安装仍待 NSIS 在正常构建环境完成。详情见 [MCP 调用说明](CanvDoAI-MCP-调用说明.md)。
