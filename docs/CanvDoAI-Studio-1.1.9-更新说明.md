# CanvDoAI Studio 1.1.9 更新说明

## 本版变化

- 加入可随 Windows 安装包交付的本机 MCP 运行时。Codex 可读取画布与任务状态，并在用户明确授权 API 消耗后运行画布节点；不用在 Codex 配置中填写业务 API Key。
- MCP 在桌面软件重启后会重新取得本机会话。已验证同一个 MCP 进程能先后读取重启前后的会话，避免沿用旧端口或令牌。
- 为 Wan 3.0 增加专用异步创建与任务轮询映射：`/api/v1/services/aigc/video-generation/video-synthesis`、`X-DashScope-Async: enable` 与 `/api/v1/tasks/{task_id}`。Seedance 等通用模型仍走原有 `/v1/video-jobs`，互不串路由。
- 画布上传参考图时根据文件后缀匹配 PNG、JPEG 或 WebP 的 MIME 类型，不再把 JPEG 一律声明为 PNG。
- 画布视频节点支持保存 `generateAudio=false` 参数；音频开关参与缓存指纹，避免误用另一种音频设置下的视频版本。默认行为仍为开启原生音频。
- 服务商拒绝请求时，尽量显示其错误码与字段级原因；日志和错误文案会遮蔽已配置的 API Key。

## 安装与连接

安装包适用于 Windows 10/11 x64，内置 FFmpeg/FFprobe 与 MCP 所需的 Node.js 运行时；不要求客户安装本地大模型。安装后在软件“API 接口设置”填入自己有权使用的接口和密钥。Codex 连接方法、工具清单及费用确认规则见 [Codex MCP 连接说明](Codex-MCP-连接.md)；其他功能见 [完整中文使用手册](完整使用手册.md)。

升级前请确认没有仍在运行的生成任务，退出桌面软件后覆盖安装。项目、画布和加密配置保存在当前 Windows 用户数据目录；不要为升级而删除 `%APPDATA%\canvdoai-desktop`。

## 验证范围与已知边界

- 已通过静态检查、单元测试、应用构建和 MCP 重连模拟测试。
- Wan 3.0 专用链路已用单个 8 秒、480p、9:16、带首帧和原生音频的真实镜头验证受理、轮询及保存版本。整部短剧的全部镜头与最终合成仍应逐镜头验收，不能仅凭首镜成功认定所有模型与素材均可用。
- 供应商的内容审核、模型额度和上传大小限制仍由其服务端决定；审核失败或退款需按服务商返回的信息处理。不要在未知状态下反复提交，以免重复计费。
- 安装包目前没有企业代码签名，Windows 可能显示“未知发布者”。请仅从此仓库的 GitHub Release 下载，并核对同页 SHA-256 文件。
