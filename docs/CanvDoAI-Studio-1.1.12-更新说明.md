# CanvDoAI Studio 1.1.12 更新说明

- 左侧“项目”改为统一项目目录，同时展示 AI 一键成片、创作画布和视频重制项目。保留原有项目 ID、素材和进度；同名作品不会被擅自合并。
- 画布项目可从统一目录直接打开。与一键成片同 ID、且没有画布的旧素材关联记录不会重复显示；独立的旧画布项目仍保留。
- 视频重制项目可从统一目录直接打开对应生产批次，不再默认跳到最近的一条。重制列表支持分页读取全部批次，不局限于最近 50 条。
- 当画布或重制服务暂时不可读时，项目页显示明确错误和刷新入口，不把读取失败误报为“没有项目”。
- 项目页不提供跨模块删除。画布、重制和一键成片继续使用各自原有的生产存档，避免升级时迁移或误删历史成果。

验证：TypeScript 静态检查、305 项自动化测试、前端及运行时构建通过。此版本尚未完成对所有供应商接口的付费生成验收；升级前请确认没有正在执行的任务，退出软件后覆盖安装，切勿删除 `%APPDATA%\canvdoai-desktop`。
