# 第三方声明材料（开发构建）

此目录由 `scripts/collect-licenses.mjs` 从实际安装的生产npm依赖复制许可证/声明原文，并生成 `inventory.json`，记录版本、路径和文件SHA-256。相同包的同版本嵌套副本可共用一份原文。

材料覆盖npm依赖，不代表整个软件已完成许可证合规审查。正式分发必须另外审查：

1. 实际编译使用的第三方代码、字体、图标、媒体和原视频重制源码的权利来源。
2. Electron/Chromium随运行时提供的许可和第三方声明。
3. FFmpeg/FFprobe实际二进制编译选项、对应源码及依赖、许可证和需要履行的分发义务。
4. 安装器内实际文件与许可材料是否一致；商业使用不免除版权/许可证义务。

WaveSurfer仅处理已提供的音频/视频，不附带模型、素材授权、降噪服务或语音生成额度。
